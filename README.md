# ¿Con quién te quedas? · ADN PLAYER

Juego de duelos de **THE EYE INTELLIGENCE UNIT**: eliges entre dos jugadores de un equipo de Primera RFEF hasta ordenar la plantilla a tu manera, y compartes tu orden en redes.

- Web estática: `index.html` + `data.js` + `fonts.css` + `fotos/<equipo>.js`. Sin dependencias externas.
- Funciona en GitHub Pages y también abriendo `index.html` directamente.
- `herramientas/`: scripts para regenerar plantillas, fotos y colores desde ADN PLAYER (no hacen falta para que la web funcione).

Escudos, nombres e imágenes pertenecen a sus clubes y propietarios.
